# HelpDesk Pro

Sistema de suporte técnico para empresas gerenciarem chamados, problemas técnicos e solicitações de clientes.

## Funcionalidades
- Abertura de chamados, categorias e prioridades
- Fluxo de status: aberto, em atendimento, resolvido
- Painel de atendentes, histórico e comentários
- SLA, métricas de atendimento e permissões por perfil

## Stack Tecnológica
- **Backend:** Java, Spring Boot
- **Frontend:** React (Vite)
- **Banco de Dados:** PostgreSQL
- **Infraestrutura:** Docker
